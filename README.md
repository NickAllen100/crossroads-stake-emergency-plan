## 1. System Architecture: The Two-Agent Debate Framework

To ensure the emergency plan is neither a detached tactical checklist nor an unfeasible wish-list, the planning process is mediated between two distinct model personas:

```
                  ┌────────────────────────────────────────────────────────┐
                  │ 00_context_and_ground_truth.md                         │
                  │ (Verified Municipal, Hospital, Utility & Church Data)  │
                  └─────────────────────────┬──────────────────────────────┘
                                            │
                                            ▼
┌─────────────────────────────────┐                   ┌──────────────────────────────────┐
│         AGENT ALPHA             │                   │           AGENT BETA             │
│  (e.g., Claude 3.7 / 3.5 Sonnet)│                   │   (e.g., OpenAI GPT-4o / o1)     │
│  Tactical Operations & Logistics│ ◄─ Round 1: Plan  │ Community Resilience & Care      │
│  - Civil Infrastructure         │ ── Round 2: Stress│ - Special Needs & Vulnerabilities│
│  - Physical Safety & Cordons    │ ◄─ Round 3: Rebut │ - Ministering Verification Net   │
│  - Hard Resource Constraints    │                   │ - Emotional First Aid & Welfare  │
└─────────────────────────────────┘                   └──────────────────────────────────┘
                                            │
                                            ▼
                  ┌────────────────────────────────────────────────────────┐
                  │ LEAD ARBITER & SYNTHESIZER                             │
                  │ - Reconciles trade-offs and checks factual accuracy    │
                  │ - Produces finalized Markdown worksheet in sequence    │
                  └────────────────────────────────────────────────────────┘
```

## 3. How to Submit to the Two Agents to Debate

You have **three flexible ways** to submit the emergency plan to your two AI agents:

### Method A: Automated CLI Execution via Live APIs (OpenAI, Anthropic, Gemini, Ollama)
Use the included zero-dependency Python orchestrator [`debate_harness/debate_orchestrator.py`](file:///Users/nickallen/code/Emergency%20plan/debate_harness/debate_orchestrator.py):

```bash
# 1. Set your API keys in your terminal
export ANTHROPIC_API_KEY="your-anthropic-key"
export OPENAI_API_KEY="your-openai-key"

# 2. Run the debate for a single phase (e.g. Page 5):
python3 debate_harness/debate_orchestrator.py --mode api --provider-a anthropic --model-a claude-3-5-sonnet-20241022 --provider-b openai --model-b gpt-4o --phase page5

# 3. Or run all 11 phases in sequence through the full pipeline:
python3 debate_harness/debate_orchestrator.py --mode api --phase all
```

*Note: You can also use local models via Ollama (`--provider-a ollama --model-a llama3.1`) or Google Gemini (`--provider-b gemini --model-b gemini-2.0-flash`).*

### Method B: Manual Web UI Submission (ChatGPT + Claude)
If you prefer to copy and paste prompts directly into the web chat interfaces (e.g., Claude.ai and ChatGPT.com), complete prompt packets have been generated in [`prompts_for_agents/`](file:///Users/nickallen/code/Emergency%20plan/prompts_for_agents/):

1. **Open your two AI chat windows:**
   - Window 1: **Claude** (Agent Alpha - Tactical Operations)
   - Window 2: **ChatGPT** (Agent Beta - Community & Human Needs)
2. **Review the Ground Truth Document:**
   - Both models should have access to [00_context_and_ground_truth.md](file:///Users/nickallen/code/Emergency%20plan/prompts_for_agents/00_context_and_ground_truth.md) so they do not invent false phone numbers or imaginary geography.
3. **Execute each phase in sequence:**
   - **Step 1:** Copy Section 1 (System Prompt) and Section 3 (Task Prompt) from the prompt file into Claude.
   - **Step 2:** Copy Claude's proposal into ChatGPT along with Section 4 (Critique Prompt).
   - **Step 3:** Copy ChatGPT's critique back to Claude for rebuttal.
   - **Step 4:** Submit Section 5 (Synthesis Prompt) to generate the final agreed markdown table.
